libwebp (BSD 3-clause), libjpeg-turbo (IJG/BSD), libpng (libpng 2.0), zlib (zlib), Skia (BSD 3-clause), libnspsl (MIT).
The CA certificate bundle is Mozilla's root list as published by curl, under the Mozilla Public License 2.0.
All licence texts are installed with this package in \resource\phweb\licences\ (NOTICE lists which file covers what).

The engine is a separate dynamic library loaded by the browser as a plug-in: you can replace it with your own build
(modified or not) of the same engine and the browser keeps working. The archives the DLL is linked from are left by the
build (see build.sh in the source below), so a modified WebKit can be relinked into the same DLL.

Corresponding source, available to anyone who has this package, for at least three years after the release you installed
it from:

     https://github.com/WebKit/WebKit, and every library listed above).
  2. Our changes to them, our own files, and the scripts that fetch, patch, build and package the engine:
       https://github.com/Phorepoc/webkit-symbian   (the release tag of this package)
     with the toolchain images and build tools in https://github.com/Phorepoc/toolchain and https://github.com/Phorepoc/pdk.
